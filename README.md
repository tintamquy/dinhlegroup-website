# Dinh Le Group Website

Professional corporate website for Dinh Le Group - a Vietnam-U.S. real estate and investment company.

## 🚀 Deploy to Cloudflare Pages

### Method 1: Direct Upload (Easiest)

1. Go to [Cloudflare Pages](https://pages.cloudflare.com/)
2. Sign in or create an account
3. Click "Create a project"
4. Select "Upload assets"
5. Drag and drop all files from this folder:
   - `index.html`
   - `about.html`
   - `us-assets.html`
   - `services.html`
   - `vietnam-operations.html`
   - `contact.html`
   - `styles.css`
   - `script.js`
6. Click "Deploy site"
7. Your website will be live in seconds!

### Method 2: Git Integration (Recommended)

1. Create a GitHub repository
2. Push all files to the repository
3. Go to Cloudflare Pages
4. Click "Create a project"
5. Connect your GitHub account
6. Select your repository
7. Build settings:
   - **Framework preset:** None
   - **Build command:** (leave empty)
   - **Build output directory:** `/` (root)
8. Click "Save and Deploy"
